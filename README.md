# Empório da Música — agente de atendimento

Protótipo de agente de mensagens de texto que atende clientes da Empório da Música, loja de
instrumentos musicais em Campo Grande/MS. Desafio técnico de AI Engineer da Artefact.

> Em construção.

## Como rodar

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS
pip install -e ".[dev]"
cp .env.example .env            # e preencha o provedor escolhido
pytest
```
